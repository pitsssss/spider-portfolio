# Peter Toss — Portfolio

Portfolio site for Peter Toss, Full-Stack Software Engineer.

## Stack

- Next.js 15 (App Router, static export)
- React 19
- TypeScript
- Three.js (npm only)

## Scripts

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Content lives in `src/content/`. Update profile, projects, skills, experience and social links there.

## Deployment

`npm run build` writes a static export to `out/`.
